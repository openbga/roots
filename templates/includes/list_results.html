Parameters: items a Django Page (page_obj) or any list/queryset; a Page adds the pagination footer noun plural noun for the count and pager, e.g. "clients" filtered truthy when a filter or search is active (e.g. active_filters|default:q); also the footer's "matching filters" invalid truthy when the filter form is invalid (filter_form.errors): the error state clear_url URL without filters, for Clear filters (default: no button) paginate False to leave out the footer for a Page post_name pagination's post mode (includes/pagination.html) empty_title, empty_body the empty state (nothing exists yet) action_url, action_label its create action; give action_url only to users who may create no_results_title, no_results_body default "No match these filters" / "Check the spelling or clear the filters." error_body default "Correct the highlighted filter above. No results are shown until every filter is valid."

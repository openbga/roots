{% comment %} Single yes-or-no confirmation of an irreversible change (docs/ui-standards.md section 8: a Bootstrap modal only for a single yes or no; anything that needs input is an action form). The button that opens it is a destructive button with data-bs-toggle="modal" data-bs-target="#{{ id }}". Parameters: id; label (verb plus object, e.g. "Close batch"); object (optional identifier, appended to the label: "Close batch B-0001"); title (optional; default the label as a question, "Close batch B-0001?"); body (one or two sentences on what it means); action (POST URL); optional hidden_name and hidden_value (one hidden input, e.g. the record revision the change was based on). Without JavaScript the opening button does nothing; pages using this dialog already need it. {% endcomment %}

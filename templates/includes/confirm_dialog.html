The button that opens it is a destructive button with data-bs-toggle="modal" data-bs-target="#{{ id }}". Parameters: id; label (verb plus object, e.g. "Close batch"); object (optional identifier, appended to the label: "Close batch B-0001"); title (optional; default the label as a question, "Close batch B-0001?"); body (one or two sentences on what it means); action (POST URL); optional hidden_name and hidden_value (one hidden input, e.g. the record revision the change was based on). Scripted form, for a choice a script acts on instead of a POST (the form dialog's "Discard unsaved changes?"): give confirm_hook instead of action. Both buttons are type="button" and carry data- / data-; cancel_label names the safe choice (default "Cancel"), which is then the primary button and takes the focus when the dialog opens. Without JavaScript the opening button does nothing; pages using this dialog already need it. {% endcomment %}

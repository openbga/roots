{% comment %} A sample matrix as a tag: a small tile in the matrix colour with its icon, then the matrix name and the sample source as text, so the colour is never the only cue. The icon of each matrix is set once, in receipt.models.MATRIX_ICONS (Water droplet-fill, Wastewater water, Soil layers-half). Rendered by the {% matrix_tag %} tag ({% load ui %}). Parameters: matrix the stored matrix value (water, wastewater, soil); another value shows a grey tile name the matrix name when it is not a stored value (a submission snapshot's label) source optional sample source text (e.g. sample.get_source_type_display). A leading matrix word is dropped from the visible text ("Wastewater effluent" shows "effluent"); the tag's title and the screen-reader text keep the whole value. A source equal to the matrix ("Soil") is left out size "sm" in dense rows, "lg" in a record header; default for lists Usage: {% matrix_tag matrix=sample.matrix source=sample.get_source_type_display %} {% endcomment %}{% load ui %}{% if icon %}{% icon name=icon %}{% endif %}{{ name }}{% if source %}· {% if short_source != source %}{{ short_source }}{{ source }}{% else %}{{ source }}{% endif %}{% endif %}
